## 快速开始

### 1. 安装依赖

```bash
pip install requests
```

### 2. 启动后端服务器

```bash
cd outputs/backend
docker compose up -d
```

### 3. 运行测试

```bash
# 使用默认配置（localhost:8080, admin/Admin@2026）
python outputs/backend/test/test_frontend_apis.py

# 指定服务器地址
python outputs/backend/test/test_frontend_apis.py --host http://192.168.1.100:8080

# 指定用户名密码
python outputs/backend/test/test_frontend_apis.py --user admin --password xxx

# 详细输出
python outputs/backend/test/test_frontend_apis.py --verbose

# 导出 JSON 报告
python outputs/backend/test/test_frontend_apis.py --report json > test_report.json
```

## 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--host` | 服务器地址 | `http://localhost:8080` |

## 在 CI/CD 中使用

### GitHub Actions 示例

```yaml
name: API 测试

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v3

      - name: 启动后端
        run: cd outputs/backend && docker compose up -d

      - name: 等待后端就绪
        run: |
          for i in {1..30}; do
            curl -f http://localhost:8080/health && break
            sleep 2
          done

      - name: 运行 API 测试
        run: |
          pip install requests
          python outputs/backend/test/test_frontend_apis.py --host http://localhost:8080

      - name: 上传测试报告
        if: always()
        run: |
          python outputs/backend/test/test_frontend_apis.py --report json > test_report.json
          
      - uses: actions/upload-artifact@v3
        with:
          name: test-report
          path: test_report.json
```

## 常见问题

### Q1: 测试失败，提示"连接失败"？

**A:** 检查：
1. 后端是否已启动（`docker compose ps`）
2. `--host` 参数是否正确
3. 防火墙是否阻止了端口

### Q2: 登录失败，提示"401"？

**A:** 检查：
1. 数据库中是否有 `admin` 用户
2. 密码是否正确（默认 `Admin@2026`）
3. 是否运行了数据库迁移脚本

### Q3: 某些测试跳过（skipped）？

**A:** 正常。某些测试需要创建数据后才能运行（如"获取老人详情"需要先创建老人）。

### Q4: 如何只测试某个模块？

**A:** 修改脚本，注释掉不需要的测试模块。或创建自定义测试脚本。

## 扩展：添加新测试

如果需要测试新增的接口，在 `APITester` 类中添加新方法：

```python
def test_new_feature(self):
    """测试新功能"""
    self._log('测试: 新功能', 'info')

    status, resp = self._request('GET', '/api/v1/new-feature')

    if status == 200 and resp.get('code') == 0:
        self._assert('新功能', True, '', resp)
    else:
        self._assert('新功能', False, f'状态码: {status}', resp)
```

然后在 `run_all_tests()` 中调用：

```python
self._log('\n' + '=' * 60, 'info')
self._log('模块 X: 新功能', 'info')
self._log('=' * 60, 'info')
self.test_new_feature()
```
