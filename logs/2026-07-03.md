## 修复签到管理页面数据与数据库不一致

**根因**：后端 `signin-service` 返回字段名和状态值与前端 `SigninRecord` 接口不匹配，导致：
1. 列表接口返回 `elderly_id/name/signin_status/signin_method/signin_at`，但前端期望 `id/elderly_id/elderly_name/signin_date/signin_time/method/status/proxy_by`
2. 状态值 `checked_in/pending/not_started/late/absent` 未映射为前端所需的 `signed/unsigned/timeout`，所有非 `signed/unsigned` 记录都落到默认的 `超时`
3. 概览接口返回 `checked_in/pending/not_started`，但前端期望 `signed/unsigned/timeout`，所以统计卡全部显示 0
4. 代签路由 `/signin/proxy-checkin` 与前端调用的 `/signin/proxy` 不一致
5. 签到日历路由 `/signin/calendar` 与前端调用的 `/signin/{elderly_id}/calendar` 不一致

**修复文件**：`backend/internal/signin/handler.go`
- `ListSignin`：返回前端标准字段，状态统一映射为 `signed/unsigned/timeout`，按未签/超时/已签排序
- `SigninOverview`：返回 `signed/unsigned/timeout/total/rate`
- `GetCommunitySignin`：同步使用 `signed/unsigned/timeout` 映射
- 路由修正：`/signin/proxy` 和 `/signin/:elderly_id/calendar`
- 新增 `database/sql` 导入以使用 `sql.NullString`

**前端补充**：`web-admin-react/src/pages/SigninManage.tsx` 增加 `watch`/`face`/`phone` 签到方式的中文显示。

## 修复签到管理页第1页无数据

**根因**：`backend/internal/signin/handler.go` 的 `ListSignin` 中 SQL 参数顺序错误。MySQL `LIMIT ?, ?` 语法是 `LIMIT offset, count`，但代码写的是 `append(filterArgs, pageSize, offset)`，把 `pageSize` 和 `offset` 写反了。导致：
- 第1页：LIMIT 8, 0 → 从第8行开始取0条，结果为空
- 第2页：LIMIT 8, 8 → 从第8行开始取8条，才有数据

**修复**：`backend/internal/signin/handler.go:326` 改为 `append(filterArgs, offset, pageSize)`。

**文件**：`backend/internal/signin/handler.go`
