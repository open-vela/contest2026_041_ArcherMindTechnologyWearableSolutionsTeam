**踩坑记录（重要经验）：**
1. JS 双引号字符串内嵌 ASCII 双引号 → SyntaxError，需改用「」或中文引号；用 `node --check` 预检
2. docx 库 `PageNumber.CURRENT` 是字符串常量不是构造器，正确用法 `new TextRun({ children: [PageNumber.CURRENT] })`
3. makeTable 的 widths 数组长度必须与每行单元格数一致，否则报 `Cannot read properties of undefined (reading 'slice')`
4. ImageRun 尺寸需按 PNG 实际纵横比计算（用 Node 读 IHDR 头 readUInt32BE(16/20)），否则图片变形
5. venv 路径实际为 `.../python/envs/default/bin/python`（bash 下需注意路径存在性），managed python 3.13.12 本体无 PIL，需 venv
