## BMI270 六轴传感器接入 BES2800BP 方案梳理

产出文档：`D:\Download\elderly-care-system\BMI270_BES2800BP_接入方案.md`（10 章）

### 关键调研结论
- **NuttX/OpenVela 主线已有 BMI270 驱动**，无需自研：`drivers/sensors/bmi270_base.c`（含 8KB 配置文件）、`bmi270.c`（字符设备）、`bmi270_uorb.c`（uORB 封装）。Kconfig 项：`CONFIG_SENSORS_BMI270` / `_UORB` / `_I2C` / `_SPI` / `LOAD_FROM_HEAP`。
- **BES2800BP 规格**：双核 Cortex-M55 + 双核 BECO NPU + BES 专有协处理器 + HiFi4 DSP（可选）+ 主机子系统双核 STAR-MC1 + 双核 BECO NPU；BT 6.1 双模 + WiFi 6；2.5D GPU + MIPI DSI 720p；6nm；外设含 SPI/I2C/UART/I2S/USB/GPIO/GPADC。
- **BMI270 关键参数**：CHIP_ID=0x24；LGA-14 2.5×3.0×0.83mm；accel ±2/4/8/16g，gyro ±125~±2000°/s；ODR accel 最高 1600Hz / gyro 3200Hz；约 6KB FIFO；I2C 地址 0x68(SDO=GND)/0x69(SDO=VDDIO)；内置计步/活动识别/显著运动/抬腕唤醒/倾斜/高低g；辅助口可挂 BMM150 成 9 轴。

### 三大技术坑（已写入文档）
1. **CSB 必须上拉 VDDIO**，否则上电误入 SPI 模式，I2C 扫不到。
2. **8KB 配置文件必须上传**（INIT_CTRL=0 → 灌 INIT_DATA 突发写≤15字节 → INIT_CTRL=1 → 等 150ms → 查 INTERNAL_STATUS bit0=1）；需先关 APS；flash 不支持 DMA 直传时须开 `LOAD_FROM_HEAP`。
3. **陀螺必须使能**，BMI270 内部 feature 引擎跑在陀螺时钟上，否则计步/活动识别静默失效。

### 发现的代码缺陷
`Silver-haired_Protector_LVGL/src/app/utils/health_rules.c` 的 `fall_detector_feed()` **Stage 2 逻辑错误**：判「最后 5 帧平均模值 > 20 m/s²」，但真实跌倒后人躺平静止，模值应回到 1g(9.8) 附近。该判定只在 mock 的 burst 段能过，**真机会漏报**。
→ 文档给出四阶段状态机替代方案：失重(|a|<3,≥5帧) → 冲击(500ms内|a|>25) → 姿态变化(Δθ>45°) → 静止(1.5s窗口 std<0.5)，并加佩戴检测 + 10s 可取消二次确认。
→ 配套改动：`constants.h` 增 ODR/四阶段阈值宏（ACCEL_BUF_SIZE 50→100）；`health_rules` 采样结构加陀螺 gx/gy/gz；`sensor_service.c` 真实分支接 uORB（sensor_accel 已是 m/s²，sensor_gyro 需确认是 rad/s 还是 °/s）。

## 实物接线补充（基于用户上传的 BES2800BP_ZE V1.3 + 6 针 BMI270 模块照片）
- 模块引脚：GND ×2、INT、SDA、SCL、3.3V（无 SDO/CSB 引出）。
- 接线：3.3V→3.3V、GND→GND、SDA→I2C_SDA、SCL→I2C_SCL、INT→支持中断/唤醒的 GPIO。
- 由于无 SDO 引脚，地址由模块内部电阻固定；多数模块下拉 SDO→0x68，需用 `i2c scan` 确认。
- 由于无 CSB 引脚，必须确认模块内部已把 CSB 上拉到 VDDIO；否则 BMI270 会停留在 SPI 模式，I2C 扫不到。
- 已更新方案文档第 2 章为「实物接线速查」，加入接线表、地址确认、CSB 排查、最小验证命令。

### BES2800BP_ZE V1.3 开发板 I2C 引脚定位
- **结论：该评估板排针定义无公开资料**（恒玄官网只有芯片 Datasheet，无 EVB pinmap）。本机也无 BES SDK 源码（已确认 `/d/AI/Xsport`、`OpenSiFli`、`.vela/sdk` 均不含 BSP；`.vela/sdk` 是快应用模拟器）。
- 已在文档 2.3 加入三种定位方法：A 查源码 IOMUX 宏（grep `platform/hal/hal_iomux*.h`、`tgt_hardware.h`、`board.h` 里的 `GPIO_I2C0_SCL`）；B 看板子丝印找 `I2C0_SCL/SDA`；C 万用表/逻辑分析仪实测上拉特征。
- **关键新发现**：BES2800BP 的 I2C 是 IOMUX 复用的，没有固定物理引脚。EVB 排针只印 Gxx/Pxx，Gxx=GPIOx。GPIO22-23 已被使用说明标注为 USB-UART0，需避开。
- **推荐接法**：I2C0_SCL→G4(GPIO4)，I2C0_SDA→G5(GPIO5)，INT1→G6(GPIO6)；软件 IOMUX 配置示例已写入文档。若 G4/G5 被占用，可换任意相邻 GPIO 对，但 IOMUX 要同步改。
- **兜底方案**：NuttX 软件 I2C（bitbang，`CONFIG_I2C_BITBANG`），任意两个 GPIO 即可，100~400 kHz，对 BMI270 @200Hz（2.4 KB/s）完全够用。建议先用 bitbang 跑通算法，再切硬件 I2C + FIFO 中断做功耗优化。

### 3.3V 供电位置
- EVB 使用说明第 5 页：左上角 **VSYS 供电插针** 经板载 DC-DC/LDO 输出 3.3V / 2.8V / 1.8V。
- BMI270 模块的 3.3V 接该插针的 3.3V 脚；GND 接左下角 GND 插针或 VSYS 插针的 GND。
- 若丝印看不清，通电后用万用表电压档量 VSYS 插针各脚，找 3.3V 即可。

### 跌倒算法数学原理（已补入文档 4.2 节「核心数学原理」）
- 物理前提：加速度计测**比力**不是运动加速度。静止读数 = 1g = 9.8 m/s²；自由落体时支撑力消失 → 读数趋近 0。这是失重检测成立的基础。
- 模值 |a| = √(ax²+ay²+az²)；失重 |a|<3 连续≥5帧(@200Hz≈25ms)；冲击 500ms 内 |a|>25。
- 姿态角：加速度静态倾角 pitch=atan2(ay,√(ax²+az²))、roll=atan2(-ax,√(ay²+az²))；陀螺积分 θ+=ω·dt 会漂移；**互补滤波 θ = α(θ+ω·dt) + (1−α)·θ_acc，α≈0.98**；Δθ>45° 判躺倒。
- 静止确认：冲击后 1.5s 窗口内 |a| 的标准差 σ<0.5。**注意静止时 |a| 仍约 9.8（重力还在），判的是方差小不是数值小** —— 这正是原代码 Stage2（avg>20）漏报的根本原因。
